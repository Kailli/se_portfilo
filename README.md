# Eaint Thwin Kyaw - Software Engineer Portfolio

Standalone portfolio for Software Engineer opportunities.

## Files

- `index.html` - Portfolio page
- `styles.css` - Responsive styling
- `script.js` - Navigation behavior

## Local Preview

Open `index.html` directly in a browser, or serve the parent folder and visit:

```bash
python3 -m http.server 8097
```

```text
http://localhost:8097/portfolio_SE/
```
